# NOCPro - Educational Repository

Welcome to the NOCPro Educational Repository. 

NOCPro is an Enterprise NOC (Network Operations Center) Operations and Operational Intelligence platform. It acts as an orchestration layer between monitoring systems (like Zabbix) and ITSM/Ticketing systems (like GLPI).

## Purpose of this Repository
This repository is designed for **educational purposes**. It contains:
- High-level Architecture and Design decisions (ADRs).
- Domain Models and concepts.
- Testing strategies.
- Public, sanitized examples of how to build modular monoliths with FastAPI, PostgreSQL, and Docker.
- Lab setups for Zabbix and GLPI.

**Note:** The actual core source code, security implementations (HMAC, JWT), and sensitive configurations are maintained in a separate private repository.

## Folder Structure
- `docs/architecture/`: ADRs and architectural concepts.
- `docs/testing/`: Testing strategies.
- `examples/`: Sanitized code snippets.
- `labs/`: Guides for setting up monitoring and ITSM tools.
- `diagrams/`: High-level architecture diagrams.
